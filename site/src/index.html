Free and open source under MIT. Build from source, bind a capture command to your favorite shortcut, and set the defaults in config.h.

Requires Linux with X11. The native executable embeds its Geist fonts and icons; no adjacent asset files or API key are needed at runtime.

Build from source

git clone https://github.com/mattmezza/s2.git
cd s2
make
sudo make install
maim -s | s2 --modal -i -

Install the native build dependencies first. Make downloads the pinned CUI dependency on the first build.

A few useful details

Before your first screenshot.

What is s2?

s2 (Super Screenshot) is a native, keyboard-first screenshot annotation editor for Linux with X11. It opens an image file or reads image data from standard input. Add arrows, lines, shapes, text, numbered pins, highlights, marker strokes, blur, and pixelation, then save a PNG or copy the result to the clipboard.

Does s2 take the screenshot too?

s2 edits the capture. Use a separate tool such as maim to take it, then pipe the image into s2: maim -s | s2 -i -. You can also open an existing image with s2 capture.png.

Does it work on Wayland, macOS, or Windows?

s2 currently targets X11 on Linux. Native Wayland, macOS, and Windows support are not provided by this release.

Where do saved images go?

Ctrl S saves and exits. Without -o, s2 creates a timestamped PNG in the configured save directory. Use -D /absolute/directory to change that directory, or -o annotated.png for an explicit output path. Explicit output paths may be overwritten. Enter only finishes text entry.

What do I need for the clipboard?

Install xclip. Ctrl C copies the rendered image and exits; Ctrl Y copies and keeps the editor open. Clipboard export includes the annotations and uses the capture's original dimensions.

Is it free? Does it need an online service?

s2 is free and open source under the MIT license. Editing runs locally and requires no account, API key, or online service. Building from a Git checkout downloads the pinned CUI source once. The executable uses the native system libraries listed in the installation guide.
